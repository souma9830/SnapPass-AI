# Extended Open-Source Contribution Workflow

## Branch Conventions
- Feature: `feat/elusoc-2026-feature-name`
- Bug Fix: `fix/elusoc-2026-bug-name`
- Refactor: `refactor/elusoc-2026-scope`
- Documentation: `docs/elusoc-2026-topic`

## Pull Request Guidelines
1. Sync `master` before creating a branch.
2. Modify 4-5+ files per PR for high-impact contributions.
3. Include raw markdown issue and PR descriptions.
4. Ensure `npm run build` passes cleanly.
