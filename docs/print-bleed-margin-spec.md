# Custom Print Layout Bleed Margin Builder

The **Custom Print Layout Bleed Margin Builder** calculates exact 300 DPI canvas dimensions and cut grid alignments to ensure error-free physical paper printing.

## Features
- Dynamic millimeter-to-pixel resolution calculation at 300 DPI.
- Interactive bleed slider control via `<PrintBleedMarginAdjuster />`.
- Server grid capacity computation via `computePrintSheetGrid()`.
- Unit tested via `frontend/src/test/__tests__/PrintBleedMarginAdjuster.test.jsx`.
